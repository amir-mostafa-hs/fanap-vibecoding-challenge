# Backend Architecture & Pipeline

The backend service is built with **FastAPI** and **Python 3.12**, designed for high throughput, safe concurrent AI operations, and resilient fallback handling.

---

## 1. Directory Structure

```text
backend/app/
├── api.py         # HTTP endpoints (REST & SSE streaming)
├── analysis.py    # Unified pipeline orchestration (synchronous & streaming generators)
├── cli.py         # Nightly batch CLI entry point
├── classify.py    # Category classification logic & keyword fallback rules
├── config.py      # Runtime configuration from environment variables
├── drafts.py      # Safe AI draft generation & safety regex validation
├── ingest.py      # Deep intake module: CSV parsing, digit normalization, order extraction & deduplication
├── llm.py         # Thread-safe LLM client with concurrent batch execution
├── sla.py         # Deep SLA module: Iranian business calendar (1405), deadline math & urgency evaluation
├── dedup.py       # Backward-compatibility bridge (re-exports from ingest.py)
├── orders.py      # Backward-compatibility bridge (re-exports from ingest.py)
└── urgency.py     # Backward-compatibility bridge (re-exports from sla.py)
```

## 2. Key Modules & Algorithms

### Deep Intake Module (`ingest.py`)
- **Single Entry Point (`load_and_canonicalize`):** Ingests raw CSV data, validates required schema headers, and produces a normalized DataFrame.
- **Timestamp Normalization:** Parses timestamps across mixed formats (ISO-8601 UTC strings, standard Gregorian dates, and Solar Hijri jalali strings).
- **Eastern-Arabic Numeral Translation:** Normalizes Persian and Arabic numerals (`۰-۹` and `٠-٩`) to ASCII (`0-9`) using `str.maketrans`.
- **Order Reference Extraction:** Identifies `BZ-<digits>` references from the dedicated `order_ref` column or automatically scans message bodies.
- **Deduplication:** Groups identical resubmissions (`customer_id` + normalized NFC body) and links duplicates to the earliest canonical `message_id`.

### Deep SLA & Urgency Module (`sla.py`)
- **Iranian Business Calendar:** Enforces Saturday–Wednesday 09:00–17:00 Tehran operating hours, excluding Thursdays, Fridays, and 26 official 1405 public holidays.
- **Deterministic SLA Deadlines (`calculate_sla_deadline`):** Computes the exact future ISO-8601 UTC timestamp (`sla_deadline_at`) when the 2-hour SLA expires.
- **Urgency Evaluation (`is_urgent`):** Evaluates whether an inquiry is urgent (`severity_hint == 'high'`, unanswered, canonical, and elapsed business hours $\ge 2.0$).

### Unified Analysis Engine (`analysis.py`)
- **Single Generator Core:** Both the real-time SSE streaming endpoint (`analyze_stream`) and the batch CLI runner (`analyze`) execute the exact same pipeline stages:
  1. `ingest`: CSV validation and timestamp parsing
  2. `dedup`: Digit normalization, order reference parsing, and canonical linkage
  3. `classify`: Concurrent LLM batch classification
  4. `sla`: Business calendar evaluation and `sla_deadline_at` calculation
  5. `complete`: Comprehensive report payload delivery

### Parallel LLM Classifier (`llm.py` & `classify.py`)
- Employs `concurrent.futures.ThreadPoolExecutor(max_workers=6)` to submit message batches (`chunk_size=20`) concurrently.
- Reduces processing time by 75% compared to serial execution, preventing gateway timeouts.
- In case of API failure, automatically falls back to rule-based keyword matching without crashing.

## 3. Safety Guardrails (`drafts.py`)

Customer reply drafts generated by the LLM are evaluated against strict regex guardrails before being returned to the UI:
- **Prohibited Commitments:** Any promises of financial refunds, compensation, monetary amounts, or delivery deadlines are blocked.
- **Safe Fallback:** Blocked drafts trigger a warning flag in the payload, requiring manual human intervention.
